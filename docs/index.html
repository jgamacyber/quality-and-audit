Funciona offline

Cada roteiro é um único arquivo HTML, sem dependências externas. Baixe e abra no Chrome, Edge ou Firefox, mesmo sem internet.

Seus dados ficam com você

As respostas ficam salvas neste navegador. Para levar a auditoria a outro computador, use Exportar backup e depois Importar backup.

Não substitui a norma

Os requisitos são perguntas de auditoria com o número da cláusula ou do controle. Confira o texto oficial e revise o roteiro antes de uma auditoria formal.
